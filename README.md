# Bonne Pousse — données météo

Données utilisées par l'application **Bonne Pousse** (Airfilm Studio).

- **Prévisions** : modèle ARPEGE 0,1° de Météo-France, mises à jour quatre fois par jour et découpées en tuiles de 1° sur la France (`/t/`).
- **Climat** : Séries Quotidiennes de Référence (SQR) de Météo-France, 30 ans de relevés par station (`/climat/`).

Source des données : **Météo-France**, données publiques sous Licence Ouverte 2.0 (Etalab). Les fichiers sont dérivés (extraction et agrégation par jour) des données d'origine.
